# წაშლისა და ვერტიკალური მონიშვნის განახლებული მოთხოვნა

თარიღი: 2026-10-11. წყარო: მომხმარებლის პირდაპირი მოთხოვნა, პუნქტები 6 და 7. სტატუსი: დასაგეგმი და დასაიმპლემენტირებელი; შესრულებულად არ ითვლება.

ეს მოთხოვნა ცვლის ადრინდელ შეთანხმებას „Delete ნაგულისხმევად შლის დროს და ყველა ტრეკზე აერთებს დარჩენილ ნაწილებს“. წინააღმდეგობისას მოქმედებს ეს ახალი წესი.

## ქცევა

| მოქმედება | შედეგი |
|---|---|
| Delete ან Backspace ნებისმიერ სელექშენზე | იშლება მხოლოდ მონიშნული მასალა. დრო არ იკუმშება; დარჩენილი ნაწილები არ ინაცვლებს და არ ერთდება. |
| Ctrl+Shift+L | არსებული მონიშნული დროის მონაკვეთი ვრცელდება მთელ ვერტიკალზე — ყველა აუდიოტრეკსა და ერთ ვიდეოხაზზე. დროის დასაწყისი და დასასრული იგივეა. ეს არ ნიშნავს მთლიანი პროექტის ხანგრძლივობის მონიშვნას. |
| Delete ან Backspace სრული ვერტიკალის მონიშვნის შემდეგ | იგივე მონაკვეთი იშლება ყველა მონიშნულ ხაზზე; სიცარიელე რჩება და მოგვიანებით განლაგებული კლიპების დრო უცვლელია. |
| Ctrl+Shift+X | ერთადერთი მოქმედებაა, რომელიც მონიშნულ დროს ამოჭრის და სიცარიელეს ხურავს: ყველა ტრეკი, ვიდეოს ჩათვლით, თანაბრად ინაცვლებს მონაკვეთის ხანგრძლივობით, სინქრონის შენარჩუნებით. |

სხვა წაშლის გზები, მათ შორის ჩვეულებრივი UI Delete და კონტექსტური წაშლა, სიცარიელეს არ ხურავს. B-მ შეაჯეროს არსებული Cut/Delete Time ღილაკები და მალსახმობები: სხვა მოქმედება ჩუმად არ უნდა იწვევდეს დროის შეკუმშვას. Ctrl+Shift+X-ის მოქმედების დანიშნულება UI-ში გასაგებად აისახოს. მისი clipboard სემანტიკა შემოწმდეს არსებული Cut Time-ის კონტრაქტთან; მომხმარებლის ამ ცვლილებით დადასტურებულია დროის ამოჭრა/შეერთების გამიჯვნა.

ტექსტურ/რიცხვით ველში წერისას Delete/Backspace არ უნდა შლიდეს თაიმლაინის მასალას. სელექშენის გარეშე წაშლა ან Ctrl+Shift+L არ უნდა იქცეს მთლიანი პროექტის წაშლად/მონიშვნად.

## მიღების შემოწმებები

1. აუდიოკლიპი 0–10 წამზე: მონიშნე 3–5 და ცალ-ცალკე შეამოწმე Delete და Backspace. დარჩეს 0–3 და 5–10; მეორე ნაწილის წყაროს offset შესაბამისი იყოს. მოგვიანებით მოთავსებული სხვა კლიპები არ გადაადგილდეს.
2. იგივე შეამოწმე ვიდეოკლიპზე, მთლიანი კლიპის არჩევაზე, რამდენიმე კლიპზე და რამდენიმე ტრეკზე. მონიშვნის ფარგლებს გარეთ მასალა უცვლელია.
3. 3–5 მონაკვეთი Ctrl+Shift+L-ით გაავრცელე ყველა ხაზზე, შემდეგ Delete/Backspace: ყველა შესაბამის ხაზზე 3–5 სიცარიელეა; შემდეგი კლიპების start უცვლელია.
4. იგივე სელექშენზე Ctrl+Shift+X: 2 წამი ამოიჭრება საერთო დროდან; ყველა შემდგომი აუდიო/ვიდეოკლიპი თანაბრად გადაიწევს. კიდეებთან გადაკვეთილი კლიპების trim/offset სწორია.
5. თითო მოქმედება Undo/Redo-თი ზუსტად აღდგება და ერთ ისტორიულ ნაბიჯს ქმნის. შეამოწმე დაკვრის პოზიცია, Loop და ვიდეო/აუდიოს სინქრონი ორივე ტიპის წაშლის შემდეგ.
6. შეამოწმე ველში ტექსტის წაშლა, ცარიელი სელექშენი და UI-ის სხვა წაშლის გზები. არცერთმა არ უნდა გამოიწვიოს დაუგეგმავი ripple.

## გადაცემა B → A → C

B-მ მომდევნო დაგეგმვისას დაამატოს მოთხოვნა backlog-სა და სტატუსის დაფაში, განაახლოს წინა Delete Time-ის კონტრაქტი და გამოყოს ცალკე მცირე რაუნდი. A-ს ზუსტი ფაილების მფლობელობა განისაზღვროს არსებული კოდის წაკითხვის შემდეგ. C-მ ზემოთ მოცემული შემთხვევები დამოუკიდებლად შეამოწმოს. მოთხოვნა მომხმარებლის პროდუქტული გადაწყვეტილებაა; Ableton-თან შესაბამისობა ცალკე წყაროთი ფასდება.
