# Studio — ვიზუალური მიმართულება A „ობსიდიანი და სპილენძი“

**თარიღი:** 2026-10-21 · **სტატუსი:** დადასტურებულია (2026-10-21), რიგშია `VISUAL-A-OBSIDIAN`: T12-ის შემდეგ, ფაზა 2-მდე · **მაკეტი:** Claude canvas „CZABA Studio — დიზაინის მიმართულებები“, დაფა A

## მომხმარებლის გადაწყვეტილებები (2026-10-21)

- მიმართულება **A** დადასტურებულია.
- **M1, M3, M4** დადასტურებულია.
- **M2:** Studio-ს ინტერფეისი მთლიანად **ინგლისურად** იქნება, როგორც Ableton-ში. CZABA საერთაშორისო პლატფორმაა, ამიტომ ტექსტები ერთ strings მოდულში გროვდება, რომ მომავალში სხვა ენების დამატება მარტივი იყოს. მომხმარებლის კონტენტი (ხმების სახელები) არ ითარგმნება.
- **M5** (ტრეკების ფერები) ჯერ არ არის დადასტურებული.
- **თანმიმდევრობა:** ფაზა 1 → T12 → ვიზუალური ეტაპი → ფაზა 2-ის დასტურის მოლოდინი.

## კონტექსტი

ახლანდელი Studio იყენებს ორ ნაჯერ აქცენტს, ფირუზისფერ #13D9CC-სა და ნარინჯისფერს, ცივ ლურჯ-შავ ფონზე. ყველა ღილაკს ჩარჩო აქვს და თითქმის ყველაფერი თანაბრად მკვეთრია, ამიტომ ინტერფეისი „AI-ით გენერირებულად“ აღიქმება. `docs/design/brand-vision.md` ამბობს: „მონოქრომული + ერთი აქცენტი (ოქროსფერი)“ და „Serif სათაურებისთვის“. მიმართულება A ამ წესს ასრულებს.

## საზღვრები (მომხმარებლის მოთხოვნა)

- **არ იცვლება:** ელემენტების პოზიციები, ზომები, layout, ფუნქციონალი, ქცევა, კლავიატურის მალსახმობები, ტექსტების შინაარსი.
- **იცვლება მხოლოდ:** ფერები, იკონები, ტიპოგრაფია (შრიფტი, წონა, ასოებს შორის დაშორება), კუთხეების მომრგვალება, ჩარჩოს ნაცვლად ფონი, hover/focus ანიმაცია.
- **ყოველი ხილული გადაადგილება** (თუნდაც 1–2 px) ცალკეა ჩამოთვლილი ქვემოთ, ცხრილში „M“, და მხოლოდ მომხმარებლის დასტურის შემდეგ კეთდება.
- Store-ის დანარჩენი გვერდები არ იცვლება: ახალი ფერები მხოლოდ Studio-ს root ელემენტზე ვრცელდება.

## როგორ კეთდება

Studio-ს კომპონენტები (`app/components/arrangement/*`) ფერებს მხოლოდ Tailwind token-ებით იყენებს: hex მნიშვნელობა არცერთ კომპონენტში არ არის. გამოყენების სიხშირე: `brand` 97, `muted` 57, `foreground` 56, `outline` 54, `accent` 42, `dim` 28, `surface` 19, `background` 18, `elevated` 9. ამიტომ ფერის ცვლილება ერთ ადგილას ხდება:

1. `StudioWorkspace`-ის root ელემენტს ემატება `data-studio-theme="obsidian"`.
2. `app.css`-ში `[data-studio-theme="obsidian"] { --color-…: … }` token-ებს მხოლოდ ამ ფარგლებში ხელახლა განსაზღვრავს.
3. კომპონენტების კლასები უცვლელი რჩება.

## იკონები

unicode სიმბოლოები იცვლება `lucide-react` იკონებით. ის store-ში უკვე დაყენებულია (^0.561.0). პარამეტრები: 16 px, `strokeWidth={1.5}`, `currentColor`.

| ახლა | lucide | ადგილი |
|---|---|---|
| ▶ | `Play` | Play, მოსმენა |
| ◀ | `ChevronLeft` | ბიბლიოთეკის ჩაკეცვა |
| ↻ | `Repeat` / `Redo2` | Loop / Redo |
| ↩ | `Undo2` | Undo, Zoom უკან |
| ✂ | `Scissors` | Split |
| ⌫ | `Delete` | წაშლა |
| ⤢ | `Maximize2` | ვიდეოს გაშლა |
| ⇔ | `MoveHorizontal` | zoom-ის ჯგუფი |

იკონის ზომა ძველი სიმბოლოს box-ს ემთხვევა, ამიტომ ელემენტი არ იძვრის.

## ღილაკები და ზედაპირები

- ჩარჩო (`border-outline`) ღილაკებზე ქრება, მის ნაცვლად ფონია: `foreground` 5%, hover 8%, active 12%. ზომა და padding უცვლელია: ჩარჩოს 1 px გამჭვირვალე ხდება და არ იშლება, რომ ზომა არ შეიცვალოს.
- ძირითადი ქმედება („Export“): ჩარჩო და ტექსტი `brand` ფერით. Play: შევსებული `foreground` ფერით, ტექსტი `background` ფერით.
- მომრგვალება: ღილაკები და ველები 8 px, პანელები 10 px. ამას layout-ზე გავლენა არ აქვს.
- სიღრმე იქმნება ზედაპირების სიღიით (background → surface → elevated) და არა ჩრდილებით.
- მოძრაობა: მხოლოდ hover/focus-ზე `transition: background-color, color 180ms cubic-bezier(.2,.8,.2,1)`. `prefers-reduced-motion`-ზე გამორთულია.

## ეტაპები ლუპისთვის (შეთანხმების შემდეგ)

0. **V-0 ინგლისური ტექსტები:** Studio-ს UI-ს ყველა ტექსტი ერთ strings მოდულში ინგლისურად; ტესტები ამ მოდულზე მიუთითებენ. ახლა ქართული ტექსტი 30 წყარო-ფაილის 282 ხაზში და 58 ტესტ-ფაილის 610 ხაზშია. 2–3 რაუნდი.
1. **V-1 ფერები:** scoped token-ები. 1 რაუნდი.
2. **V-2 ტიპოგრაფია:** შრიფტების ჩატვირთვა და როლები. 1 რაუნდი.
3. **V-3 იკონები და ღილაკები:** lucide, ჩარჩოს ნაცვლად ფონი, მომრგვალება. 1–2 რაუნდი.
4. **M1, M3, M4:** თითო-თითო. **M5** მხოლოდ ცალკე დასტურით.

## შემოწმება (C)

- 1280×720 და 1440×900 ეკრანზე ყველა ღილაკისა და ველის bounding box ძველს ემთხვევა ±1 px სიზუსტით. ერთადერთი გამონაკლისი დადასტურებული M-ებია.
- ტექსტის კონტრასტი ≥ 4.5:1, დიდი ტექსტისა და იკონებისთვის ≥ 3:1.
- კომპონენტებში hex ფერი არ არის, token-ები მხოლოდ `[data-studio-theme]`-შია.
- Store-ის სხვა გვერდების screenshot-ები უცვლელია.
- `npm run verify` გადის. ფუნქციონალის ყველა ტესტი უცვლელად გადის.
