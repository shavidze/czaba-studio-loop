## LAME MP3 Encoder

This product uses LAME.

The MP3 export uses the LAME MP3 Encoder (LAME 3.100), compiled to WebAssembly by the
`@mediabunny/mp3-encoder` package (MPL-2.0). The WebAssembly binary is inlined (base64) in
that package's JavaScript and is embedded unmodified. The package's JavaScript itself is
bundled and minified together with the application's own code by the build tool. It is
loaded only when the user starts an MP3 export.

LAME is licensed under the LGPL; its licence page does not state a version.

- LAME project: https://lame.sourceforge.io/
- LAME licence: https://lame.sourceforge.io/license.txt
- LAME source download: https://sourceforge.net/projects/lame/files/lame/
- Encoder package source: https://github.com/Vanilagy/mediabunny/tree/main/packages/mp3-encoder

LAME's licence page names `www.mp3dev.org` for its web site; the project now lives at
lame.sourceforge.io.
