# ლიცენზიები და პროდუქტის ვერსიები

## ლიცენზიები

### 1. უნივერსალური კრეატორის ლიცენზია

ეს ლიცენზია იდეალურია კონტენტ კრიეატორებისა და ბიზნესების უმრავლესობისთვის. ერთჯერადი გადახდით თქვენ იღებთ უფლებას, გამოიყენოთ პროდუქტი ულიმიტო რაოდენობის კომერციულ თუ პირად პროექტებში (YouTube, ონლაინ რეკლამა, სოციალური მედია) სამუდამოდ, ნახვების რაოდენობის შეზღუდვის გარეშე. ეს არის ყველაზე მარტივი და თავისუფალი გზა, რომ დაამატოთ მაღალი ხარისხის საუნდი თქვენს ნამუშევრებს ყოველგვარი დამატებითი საზრუნავის გარეშე.

### 2. კორპორატიული / ინდივიდუალური ლიცენზია

ეს ლიცენზია განკუთვნილია მსხვილი მედია კომპანიებისა და ფართომასშტაბიანი პროექტებისთვის, როგორიცაა კინოფილმები, სატელევიზიო და რადიო მაუწყებლობა ან მაღალბიუჯეტიანი ვიდეო თამაშები.

## ძირითადი კონცეფცია: პროდუქტის ვარიანტები (Product Variants)

თქვენ არ გჭირდებათ ორი სხვადასხვა პროდუქტის შექმნა. თქვენ ქმნით **ერთ პროდუქტს** (მაგ. "Epic Cinematic Track") და ამ პროდუქტს უმატებთ **ვარიანტებს**.

*   **ვარიანტი 1:** Standard
*   **ვარიანტი 2:** Premium

თითოეულ ვარიანტს ექნება საკუთარი ფასი და, რაც მთავარია, მასზე მიბმული საკუთარი ციფრული ფაილი.

## ადმინისტრატორის მოქმედებები

### User Story 1: პროდუქტის ვარიანტების შექმნა

*   **როგორც მაღაზიის მფლობელს,** პროდუქტის გვერდზე მე ვქმნი პროდუქტს ორი ვარიანტით: "Standard" ($19) და "Premium" ($49).
*   **მიზანი:** მომხმარებლისთვის ფასისა და ვერსიის არჩევის შესაძლებლობის მიცემა.

### User Story 2: ფაილების ატვირთვა და მიბმა

*   **როგორც მაღაზიის მფლობელს,** ციფრული გადმოწერების სისტემაში:
    1.  მე ვპოულობ ჩემს პროდუქტს და მის "Standard" ვარიანტს ვამაგრებ **ერთ ფაილს:** `Standard_Package.zip`.
    2.  შემდეგ, "Premium" ვარიანტს ვამაგრებ **ორ, ცალ-ცალკე ფაილს:**
        *   `Standard_Package.zip`
        *   `Premium_Package.zip`
*   **მიზანი:** იმის უზრუნველყოფა, რომ სისტემამ Premium მყიდველს მიაწოდოს წვდომა ორივე პაკეტზე.

## მომხმარებლის გამოცდილება

### User Story 3: Standard ვერსიის შეძენა

*   **როგორც მომხმარებელს,** რომელმაც შეიძინა "Standard" ვერსია, შეძენის შემდეგ მე ვიღებ იმეილს და წვდომას გადმოწერის გვერდზე, სადაც არის **ერთი ლინკი** `Standard_Package.zip`-ის გადმოსაწერად.
*   **მიზანი:** მარტივი და პირდაპირი წვდომა ჩემს მიერ შეძენილ ფაილზე.

### User Story 4: Premium ვერსიის შეძენა და გადმოწერის არჩევანი

*   **როგორც მომხმარებელს,** რომელმაც შეიძინა "Premium" ვერსია, შეძენის შემდეგ მე ვიღებ იმეილს და წვდომას გადმოწერის გვერდზე, სადაც ვხედავ **ორ მკაფიოდ დასახელებულ, განცალკევებულ გადმოწერის ლინკს:**
    1.  **ლინკი 1:** `Download Standard Version (MP3, 16-bit WAV) - 50MB`
    2.  **ლინკი 2:** `Download Premium Version (Stems, 24-bit WAV) - 900MB`
*   **მიზანი:** მქონდეს სრული თავისუფლება, გადმოვწერო მხოლოდ ის პაკეტი, რომელიც იმ მომენტში მჭირდება, იქნება ეს მცირე ზომის Standard თუ სრული Premium პაკეტი.
