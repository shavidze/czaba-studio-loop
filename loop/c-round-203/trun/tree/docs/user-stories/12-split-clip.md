# სტემის კონკრეტული ნაწილის ამოჭრა (Split Clip)

## User Story:

**როგორც** მუსიკალური პროდიუსერი, **მინდა**, რომ დრამის სტიმიდან ამოვჭრა კონკრეტული მონაკვეთი, მაგალითად, მხოლოდ სოლო დასარტყამი ინსტრუმენტის ჟღერადობის ნაწილი, **რათა** შევძლო ამ მონაკვეთის სხვა ადგილას გამოყენება ან მისი წაშლა და კომპოზიციის არანჟირების შეცვლა.

**მიზანი:** დაინერგოს SplitClip ფუნქციონალი, რომელიც არჩეულ აუდიო რეგიონს ყოფს ორ დამოუკიდებელ ობიექტად.

---

## Ableton-ის ლოგიკის ანალიზი (როგორ მუშაობს "ქვედა ფენებში")

როდესაც Ableton-ში აჭერ Ctrl+E (Split):

1. სისტემა პოულობს იმ კლიპს, რომელზეც დგას "Playhead" (დროის მაჩვენებელი).
2. ის არ ჭრის აუდიო ფაილს ფიზიკურად. ის კლონირებს კლიპის ობიექტს.
3. **მარცხენა ნაწილი:** ინარჩუნებს ძველ StartTime-ს, მაგრამ უმცირდება Duration.
4. **მარჯვენა ნაწილი:** იღებს ახალ StartTime-ს და ეცვლება Offset (საიდან უნდა დაიწყოს ფაილის კითხვა).

აქამდე თუ გვქონდა Track, ახლა გვჭირდება Clip. ტრეკი ხდება "კონტეინერი".

---

## მონაცემთა სტრუქტურა

```typescript
// ძველი მიდგომა: Track = Audio File
// ახალი მიდგომა: Track შეიცავს Clip-ების მასივს

interface Clip {
  id: string;           // უნიკალური ID
  trackId: string;      // რომელ ტრეკზე დევს
  buffer: AudioBuffer;  // რეალური აუდიო მონაცემი (ყველა კლიპი ერთსა და იმავე Buffer-ს იყენებს RAM-ში)

  // პოზიციონირება Timeline-ზე
  startTime: number;    // სად იწყება ტრეკზე (მაგ: მე-10 წამზე)
  duration: number;     // რამდენ ხანს გრძელდება (მაგ: 5 წამი)

  // აუდიო ფაილის შიდა ნავიგაცია (Crucial for Splitting!)
  offset: number;       // აუდიო ფაილის მერამდენე წამიდან უნდა დაუკრას (Start Offset)
}
```
