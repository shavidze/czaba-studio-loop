# SFX — უნივერსალური ლიცენზია

## ქცევა

SFX კოლექციას აქვს ერთი Universal შეთავაზება. Shopping Mall Ambience-ის ფასი არის $49; კოლექცია შეიცავს 10 ორიგინალ WAV ჩანაწერს 96 kHz / 24-bit ხარისხით. მუსიკის Standard/Premium არჩევანი უცვლელია.

შეძენილი SFX კოლექციის გვერდზე და Downloads-ში „Open in Studio“ ხსნის `/recordings/{productId}` სივრცეს. ჩანაწერების მოსმენა და Quick Edit ეფუძნება სერვერის მიერ დადასტურებულ შესყიდვას. გაუქმებული, დაუფარავი და დაბრუნებული შეკვეთები უფლებას არ ანიჭებს.

„What's Included“ და „License & Usage“ თავდაპირველად დახურული, კლავიატურით სამართავი აკორდეონებია.

## ისტორიული შესყიდვები

Shopping Mall-ის ძველი Standard და Premium შესყიდვების მონაცემები უცვლელია. Backend-ის migration 016 ვარიანტ 20-ს Universal-ად გარდაქმნის; ვარიანტი 19 რჩება შეკვეთების ისტორიისთვის. ორივე ძველი შესყიდვის მოქმედი მფლობელი იღებს Universal წვდომას.

არქივის ფიზიკური სახელი რჩება `premium.zip`; ეს შენახვის დეტალია და მომხმარებელს დამატებით ფასიან ვერსიას არ სთავაზობს. Universal უფლება მუსიკალური სტემების Premium უფლებას არ უდრის.

## გამოქვეყნების რიგი

ჯერ სრულდება Backend migration 016 და Backend-ის გამოქვეყნება, შემდეგ Store და Admin. Quick Edit-ისთვის ცალკე საჭიროა დაცული ორიგინალი WAV ობიექტები. ახალი SFX პროდუქტის შექმნისას Admin უშვებს მხოლოდ ერთ Universal ვარიანტს; ისტორიული ვარიანტები არ იშლება.
