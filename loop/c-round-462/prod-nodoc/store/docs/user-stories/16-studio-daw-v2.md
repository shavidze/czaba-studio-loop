# Personal Mixdown Studio v2.0

## საბოლოო დავალება დასამტკიცებლად: "Personal Mixdown Studio" v2.0

## User Story (საბოლოო):

**As a** კრეატიული პროფესიონალი,
**I want to** მქონდეს ერთიანი მთავარი თაიმლაინი, რომელიც აკონტროლებს დაკვრის პოზიციას ყველა ტრეკისთვის ერთდროულად, მქონდეს კონკრეტული სექციისთვის გლობალური ლუპის დაყენების შესაძლებლობა, და მქონდეს ცალკე, დამოუკიდებელი კონტროლები, რომ დავასოლოო ან გავაჩუმო ნებისმიერი ტრეკი ამ კონტექსტის ფარგლებში,
**So that I can** ფოკუსირება მოვახდინო არანჟირების კონკრეტული ნაწილების დახვეწაზე ისე, რომ მესმოდეს ისინი სრული მიქსის კონტექსტში, ზუსტად ისე, როგორც ამას პროფესიონალურ დესკტოპ პროგრამაში ვიზამდი.

---

## ფუნქციონალის დეტალური მოთხოვნები:

### ნაწილი 1: მთავარი თაიმლაინი და ნავიგაცია (რულერი)

1. **მთავარი თაიმლაინი:** რედაქტორის თავში უნდა იყოს ერთი, გლობალური თაიმლაინი (რულერი), რომელიც აკონტროლებს დაკვრის პოზიციას **ყველა სტემისთვის ერთდროულად**.

2. **ვიზუალი:** რულერი უნდა იყოს დაყოფილი **ტაქტებად და ბითებად (Bars and Beats)**, პროექტის BPM-ის გათვალისწინებით.

3. **კლიკით ნავიგაცია:** რულერზე ერთი კლიკი მყისიერად უნდა გადაადგილებდეს მთავარ კურსორს (Playhead) შესაბამის პოზიციაზე.

4. **ზუმი:** რულერზე კლიკით და ვერტიკალური მოძრაობით უნდა კონტროლდებოდეს მთლიანი არანჟირების ჰორიზონტალური მასშტაბი.

5. **Sticky Header:** ეს მთლიანი მთავარი თაიმლაინის/რულერის სექცია უნდა დარჩეს ეკრანის ზედა ნაწილში მიწებებული, როდესაც მომხმარებელი ქვემოთ ჩასქროლავს.

---

### ნაწილი 2: გლობალური ლუპი (დაკვრის "ფანჯარა")

6. **ლუპის რეგიონი:** მომხმარებელს შეუძლია შექმნას "Loop Brace" (მონიშვნა) **მხოლოდ მთავარ რულერზე**. ეს განსაზღვრავს გლობალურ ლუპს მთელი პროექტისთვის.

7. **ლუპის ჩამრთველი:** მთავარ სამართავ პანელში (Play/Pause-ის გვერდით) არის ერთი, გლობალური "Loop Switch" ღილაკი.

8. **ლუპის ლოგიკა:**
* როდესაც "Loop Switch" **ჩართულია**, მთავარი კურსორი უსასრულოდ იმოძრავებს ლუპის რეგიონის საზღვრებში.
* ეს ეხება **ყველა** ტრეკს ერთნაირად.
* როდესაც "Loop Switch" **გამორთულია**, ლუპის რეგიონი იგნორირებულია.
