# გადახდის პროცესი (Payment Flow)

## User Story: უსაფრთხო გადახდა და მყისიერი წვდომა პროდუქტზე

**As a** მომხმარებელი, რომელმაც დაასრულა გადახდის პროცესი,
**I want to** ვიყო ავტომატურად დაბრუნებული თქვენს საიტზე, ვნახო შეკვეთის დადასტურების მკაფიო გვერდი და დაუყოვნებლივ მივიღო წვდომა ჩემს მიერ შეძენილ პროდუქტებზე "My Downloads" სექციაში,
**So that I can** ვიყო დარწმუნებული, რომ ჩემი ტრანზაქცია წარმატებით დასრულდა და შემიძლია დაუყოვნებლივ, ყოველგვარი დაბრკოლების გარეშე დავიწყო ჩემი ახალი პროდუქტების გამოყენება.

---

## პროცესის დეტალური აღწერა (Acceptance Criteria):

### ფაზა 1: Stripe-ის მხარე და უკან დაბრუნება (Redirect)

1.  **გადახდის დასრულება:** მომხმარებელი წარმატებით ავსებს გადახდის ინფორმაციას Stripe-ის დაცულ `checkoutUrl`-ზე და აჭერს "Pay Now".
2.  **ავტომატური გადამისამართება:** ტრანზაქციის წარმატებით დასრულების შემდეგ, Stripe ავტომატურად უნდა გადაამისამართოს მომხმარებელი ჩვენს საიტზე წინასწარ განსაზღვრულ მისამართზე (მაგ. `/checkout/success`).

### ფაზა 2: ჩვენი სისტემის ფონური მუშაობა (Webhook - ყველაზე კრიტიკული ნაწილი)

1.  **შეტყობინების მიღება:** გადახდის დამუშავებისთანავე, Stripe აგზავნის Webhook შეტყობინებას ჩვენს სერვერულ ენდპოინტზე.
2.  **ინფორმაციის დამუშავება:** ჩვენი სერვერული ფუნქცია:
    *   იღებს და ამოწმებს (validates) Webhook-ს, რათა დარწმუნდეს, რომ ის ნამდვილად Stripe-დანაა.
    *   შეტყობინებიდან იღებს ინფორმაციას: მომხმარებლის ID და შეძენილი პროდუქტების სია.
    *   განაახლებს Order-ის სტატუსს "Paid"-მდე.
    *   აგზავნის გადახდის დადასტურების email-ს.
3.  **პროცესის დასრულება:** ეს ყველაფერი ხდება რამდენიმე წამში, ფონურ რეჟიმში.

### ფაზა 3: მომხმარებლის გამოცდილება ჩვენს საიტზე

1.  **შეკვეთის დადასტურების გვერდი:** მომხმარებელი ხვდება `/checkout/success` გვერდზე, სადაც მას ხვდება:
    *   მკაფიო მადლობის შეტყობინება: "გმადლობთ შენაძენისთვის!"
    *   შეკვეთის ნომერი და მოკლე შეჯამება.
    *   ერთი, მთავარი და თვალსაჩინო ღილაკი: **"ჩემს გადმოწერებზე გადასვლა" (Go to My Downloads)**.
2.  **მყისიერი წვდომა:** როდესაც მომხმარებელი ამ ღილაკს დააჭერს, ის გადადის "My Downloads" გვერდზე. რადგან ფონურმა პროცესმა (Webhook) უკვე იმუშავა, **მისი ახლად შეძენილი პროდუქტები უკვე იქ ხვდება**, მზად გადმოსაწერად.

---

## ტექნიკური მოთხოვნები:

### Backend (Webhook Endpoint):
1.  შექმენი API ენდპოინტი (მაგ., `/api/payments/webhook`), რომელიც მიიღებს Stripe-ის Webhook-ს.
2.  დაამატე Webhook-ის ვალიდაციის ლოგიკა Stripe-ის signature ჰედერით.
3.  გაანალიზე მიღებული მონაცემები, რათა ამოიღო მომხმარებლის ID და შეძენილი პროდუქტების სია.
4.  განაახლე Order status და გააგზავნე confirmation email.

### Frontend (React):
1.  შექმენი ახალი გვერდი `/checkout/success`.
2.  ამ გვერდზე განათავსე მკაფიო დადასტურების შეტყობინება და ღილაკი, რომელიც მომხმარებელს გადაიყვანს "My Downloads" გვერდზე.
