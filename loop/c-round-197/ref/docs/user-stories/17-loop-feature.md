# ლუპი (Loop Feature)

## User Story:

**As a** პროდიუსერი, **I want to** შევძლო ნებისმიერი აუდიო მონაკვეთის მონიშვნა და შემდეგ ერთი ბრძანებით ამ მონაკვეთის ლუპად ქცევა, ასევე მქონდეს ამ ლუპის დინამიურად რედაქტირების და ერთი კლიკით გათიშვის შესაძლებლობა, **so that I can** ვიმუშაო სწრაფად, კრეატიულად და პროცესის შეწყვეტის გარეშე.

---

## ფუნქციონალის დეტალური მოთხოვნები:

### 1. ლუპის რეგიონის (Loop Brace) შექმნის ორი გზა:

- **მეთოდი A (პირდაპირი მართვა):** მომხმარებელს უნდა შეეძლოს **მთავარ რულერზე** მაუსის დაჭერით და გაწევით (Drag) ლუპის რეგიონის პირდაპირ შექმნა და მონიშვნა.

- **მეთოდი B (მონიშვნით და ბრძანებით):**
    - მომხმარებელს უნდა შეეძლოს ნებისმიერი სტემის Waveform-ზე დროის მონაკვეთის მონიშვნა.
    - Ctrl+L (ან Cmd+L) კლავიატურის კომბინაციაზე დაჭერისას, სისტემამ ავტომატურად უნდა შექმნას ლუპის რეგიონი ამ მონიშვნის საზღვრებში **და** ჩართოს გლობალური ლუპის რეჟიმი.

---

### 2. ლუპის აქტივაცია და დეაქტივაცია:

- **გლობალური ჩამრთველი (Loop Switch):** მთავარ პანელზე უნდა იყოს ერთი, გლობალური Loop ღილაკი.

- **კლავიატურის კომბინაცია:** Ctrl+L / Cmd+L უნდა მუშაობდეს გადამრთველის პრინციპით:
    - თუ ლუპი გამორთულია, რთავს მას.
    - თუ ლუპი ჩართულია, თიშავს მას.

---

### 3. ლუპის რეგიონის რედაქტირება:

- ლუპის რეგიონი (რომელიც რულერზე ჩანს) უნდა იყოს რედაქტირებადი:
    - **ზომის შეცვლა:** შესაძლებელი უნდა იყოს მისი საწყისი და საბოლოო წერტილების მაუსით ჩავლება და გამოწევა.
    - **გადაადგილება:** შესაძლებელი უნდა იყოს რეგიონის შუა ნაწილზე ჩავლებით მისი მთლიანად გადაადგილება თაიმლაინზე.

---

### 4. დაკვრის ლოგიკა:

- დაკვრა უნდა ხდებოდეს ციკლურად **მხოლოდ მაშინ, როდესაც გლობალური Loop Switch ჩართულია.**
- თუ Switch გამორთულია, სისტემამ სრულად უნდა დააიგნოროს ლუპის რეგიონის არსებობა.

ეს განახლებული დავალება სრულად ასახავს პროფესიონალური DAW-ის ლოგიკას და შექმნის საუკეთესო მომხმარებლის გამოცდილებას.
