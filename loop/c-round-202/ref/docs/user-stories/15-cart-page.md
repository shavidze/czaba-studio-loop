# კალათა (Cart Page)

## User Story: ნათელი და კონტროლირებადი კალათა

**As a** მომხმარებელი, რომელმაც ერთი ან მეტი პროდუქტი დაამატა კალათაში,
**I want to** შევძლო ჩემი არჩევანის ერთ გვერდზე ნახვა, სადაც ნათლად იქნება წარმოდგენილი თითოეული პროდუქტი, მისი ფასი და საერთო ჯამური თანხა, ასევე მქონდეს არასასურველი პროდუქტის მარტივად წაშლის შესაძლებლობა,
**So that I can** მივიღო საბოლოო, ინფორმირებული გადაწყვეტილება და სრული თავდაჯერებულობით გადავიდე გადახდის უსაფრთხო გვერდზე.

---

## ფუნქციონალის დეტალური აღწერა (Acceptance Criteria):

### ტექნიკური მოთხოვნები:

1. **კომპონენტის სტრუქტურა:** შექმენი ახალი გვერდის კომპონენტი `/cart` მარშრუტზე.

2. **მონაცემების ჩატვირთვა:** გვერდის ჩატვირთვისას, წამოიღე კალათის აქტუალური მდგომარეობა Backend API-დან.

3. **პროდუქტების სიის რენდერი:** დინამიურად დაარენდერე კალათაში არსებული პროდუქტები. თითოეულ პროდუქტს უნდა ჰქონდეს სურათი, სრული სახელი, ფასი და წაშლის ღილაკი.

4. **პროდუქტის წაშლის ლოგიკა:**
    - წაშლის ღილაკზე დაჭერამ უნდა გამოიძახოს `removeCartItem` API endpoint შესაბამისი `itemId`-ით.
    - წარმატების შემთხვევაში, განაახლე მთლიანი UI (კალათის სია, ჯამური თანხა, ჰედერის იკონკა).

5. **Order Summary:** აჩვენე subtotal და total თანხები კალათის ობიექტიდან.

6. **ცარიელი კალათის UI:** დაამუშავე შემთხვევა, როდესაც კალათა ცარიელია, და აჩვენე "Your cart is empty" შეტყობინება და "შოპინგის გაგრძელების" ბმული.

7. **გადახდის ღილაკი, ავტორიზაციის შემოწმებით (კრიტიკულია):**

    - **"Proceed to Checkout"** ღილაკის ქცევა უნდა იყოს პირობითი.

    - **თუ** მომხმარებელი **ავტორიზებულია**:
        - ღილაკმა პირდაპირ უნდა გადაამისამართოს მომხმარებელი checkout URL-ზე.

    - **თუ** მომხმარებელი **არ არის ავტორიზებული**:
        - ღილაკმა **არ უნდა** გადაამისამართოს Stripe-ზე.
        - სამაგიეროდ, მისმა onClick ფუნქციამ უნდა გამოიძახოს **უკვე არსებული ავტორიზაციის Pop-up ფანჯარა**.
        - **Pop-up-ში წარმატებული ავტორიზაციის/რეგისტრაციის შემდეგ**, უნდა მოხდეს კალათის დაკავშირება ავტორიზებულ მომხმარებელთან.
        - კალათის დაკავშირების შემდეგ, მომხმარებელს უნდა შეეძლოს "Proceed to Checkout" ღილაკზე ხელახლა დაჭერა.
