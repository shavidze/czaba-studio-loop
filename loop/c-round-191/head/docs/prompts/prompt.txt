### დავალება: My Account გვერდი

**User Story:**

**As a** რეგისტრირებული მომხმარებელი,
**I want to** მქონდეს "My Account" გვერდი, სადაც შევძლებ პროფილის რედაქტირებას და პაროლის შეცვლას,
**So that** მქონდეს კონტროლი ჩემს პერსონალურ ინფორმაციაზე და ანგარიშის უსაფრთხოებაზე.


**ტექნიკური მოთხოვნები:**

1. **Route:** `/account` - დაცული მარშრუტი (RequireAuth)

2. **Profile Section:**
   - Email: read-only (Shopify არ აძლევს შეცვლას)
   - First Name, Last Name: რედაქტირებადი
   - Update: Shopify `customerUpdate` mutation
   - Firebase backup-ის განახლებაც

3. **Password Section (მხოლოდ Email/Password users-თვის):**
   - Current Password, New Password, Confirm Password
   - Validation: passwords match, min 8 chars
   - Re-auth: `customerAccessTokenCreate` მიმდინარე პაროლით
   - Update: `customerUpdate` mutation ახალი პაროლით
   - Social login users-თვის: სექცია დამალული

4. **Registration Source Detection:**
   - User object-ში `registrationSource` დამატება
   - ან Firebase backup-დან წამოღება


**დიზაინის მოთხოვნები:**

- Dark theme (vision.txt შესაბამისად)
- მინიმალისტური, 2 სექცია (cards)
- Framer Motion ანიმაციები (fade in)
- Toast notifications (success/error)
- Loading states ღილაკებზე
- Responsive: mobile-first


**ფაილების სტრუქტურა:**

```
app/
├── routes/
│   └── account.tsx              # My Account გვერდი
├── lib/
│   ├── auth.ts                  # + updateProfile, updatePassword
│   └── shopify.queries.ts       # + CUSTOMER_UPDATE_MUTATION
└── components/account/          # (optional) Account კომპონენტები
```


**Acceptance Criteria:**

- [ ] /account route დაცულია, გადამისამართება login-ზე თუ არ არის auth
- [ ] Email ველი ჩანს, მაგრამ disabled
- [ ] First/Last Name რედაქტირდება და ინახება Shopify-ში
- [ ] Firebase backup-იც განახლდება
- [ ] Password სექცია ჩანს მხოლოდ email/password users-თვის
- [ ] Current password verification მუშაობს
- [ ] არასწორი password-ზე error message
- [ ] წარმატებულ შენახვაზე Toast notification
- [ ] Loading states ყველა action-ზე
- [ ] Mobile responsive

## 🎨 Design System (აუცილებელი!)

**წაიკითხე სტილის დაწერამდე:** `docs/design/DESIGN_SYSTEM.md`

### კომპონენტები
```tsx
// ✅ გამოიყენე არსებული კომპონენტები
import { Button, IconButton } from '~/components/ui';

<Button variant="primary" size="lg">Add to Cart</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="ghost" size="sm">Learn More</Button>
```

### წესები
- **არასოდეს** დაწერო custom button - გამოიყენე `Button` კომპონენტი
- **არასოდეს** გამოიყენო arbitrary values (px) - მხოლოდ tokens
- **Colors:** `bg-brand`, `text-muted`, `border-outline`
- **Spacing:** 4px base - `spacing-4`, `spacing-6`, `spacing-8`
- **Animation:** `transition-fast`, `hover-lift`, `animate-fadeIn`

### WCAG
- Contrast გასწორებულია - იხ. `docs/design/wcag-audit.md`
- `--color-dim` და `--color-outline` განახლებულია
