# Design Philosophy - Portfolio Sites

## მოძიებული კვლევები და თეორიები

### 1. Perceived Value Theory

**წყარო:** [Interaction Design Foundation](https://www.interaction-design.org/literature/article/customer-and-user-perception-of-value-and-what-it-means-to-designers)

მომხმარებელი აფასებს პროდუქტს 4 განზომილებით:

| Value Type | აღწერა | SIZMARA-ში როგორ |
|------------|--------|------------------|
| **Functional** | რას აკეთებს | ნათლად ჩანს: Composer, Sound Designer, Film Scoring |
| **Financial** | ფასი vs ღირებულება | არ არის relevant (პორტფოლიო) |
| **Social** | სოციალური აღქმა | 24M streams, IMDb, 184 countries = credibility |
| **Psychological** | როგორ გაგრძნობინებს | Dark cinematic aesthetic = "ეს პროფესიონალია" |

> **დასკვნა:** პორტფოლიო საიტზე **Psychological value** ყველაზე მნიშვნელოვანია. ვიზუალი = ნდობა.

---

### 2. Aesthetic-Usability Effect

**წყარო:** [UXBert](https://uxbert.com/ux-psychology-principles-design-ux/)

> "რაც უფრო ლამაზია, უფრო usable-ად აღიქმება - მაშინაც კი თუ ფუნქციონალურად იდენტურია"

კვლევა აჩვენებს:
- მომხმარებლები **აპატიებენ** usability პრობლემებს თუ დიზაინი ლამაზია
- პირველი შთაბეჭდილება 50ms-ში იქმნება
- ვიზუალური appeal = perceived quality

**SIZMARA-სთვის:**
- Dark theme = cinematic, premium feel
- Clean typography = professional
- Whitespace = "სუნთქვა", არა გადატვირთული

---

### 3. Visual Hierarchy & Storytelling

**წყარო:** [Interaction Design Foundation](https://www.interaction-design.org/literature/article/design-with-intent-craft-your-portfolio-with-visual-storytelling-tools)

> "Your portfolio should function as a narrative journey that guides viewers through your creative thinking"

**სტრუქტურა რომელიც მუშაობს:**

```
1. Hook (Hero)      → ვინ ხარ - პირველი შთაბეჭდილება
2. Proof (Stats)    → რიცხვები - credibility
3. Evidence (Work)  → ნამუშევრები - დაამტკიცე
4. Listen (Music)   → გამოცდა - მოისმინოს
5. Depth (About)    → სიღრმე - გაიცნოს
6. Services         → რას სთავაზობ
7. CTA (Contact)    → მოქმედება
```

### 4. 79% Background Info Stat

**წყარო:** [Wix Artist Websites Research](https://www.wix.com/blog/artist-websites)

> "79% პოტენციური მყიდველების მეტ background information-ს ითხოვს არტისტზე შესყიდვამდე"

**რას ნიშნავს:**
- ფოტო **აუცილებელია**
- პერსონალური ისტორია მნიშვნელოვანია
- "Behind the scenes" კონტენტი conversion-ს ზრდის

**SIZMARA-ში:**
- ✅ ფოტოები (sizmara-1.jpg, sizmara-2.jpg)
- ✅ About section ბიოგრაფიით
- △ Video/Showreel დასამატებელია
