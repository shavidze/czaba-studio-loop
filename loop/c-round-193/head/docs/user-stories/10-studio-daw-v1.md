# სტუდიო - Personal Mixdown Studio (v1)

ეს არის ძალიან ძლიერი და პროფესიონალური ხედვა, რომელიც ჩვენს რედაქტორს ერთი საფეხურით მაღლა აიყვანს და მიაახლოებს დესკტოპ პროგრამების გამოცდილებას.

---

## დავალება: რედაქტორის განახლება პროფესიონალურ "მიკრო-DAW" ინტერფეისად

ჩვენ მნიშვნელოვნად ვაუმჯობესებთ "Personal Mixdown Studio"-ს ხედვას. მიზანია, შევქმნათ მძლავრი, ბრაუზერზე დაფუძნებული "მიკრო-DAW", რომელიც მომხმარებელს შესთავაზებს პროფესიონალურ და ინტუიციურ სამუშაო გარემოს, Ableton-ის მსგავსი ხელსაწყოების შთაგონებით.

---

## User Story:

**As a** პროფესიონალი კონტენტ კრეატორი, **I want to** ვმართო Stem-ები კომპაქტურ, მრავალზოლიან რედაქტორში, რომელსაც აქვს ზუსტი დროის ხაზი (Timeline), მასშტაბირების (Zoom) და ზოლების ზომის შეცვლის ფუნქცია; მქონდეს "მაკრატლის" (Split) ინსტრუმენტი კლიპების ნებისმიერ ადგილას გასაჭრელად და თითოეული ნაწილის ინდივიდუალურად დალუპვის (Loop) შესაძლებლობა, **so that I can** შევასრულო დეტალური, მილიწამების სიზუსტის რედაქტირება და შევქმნა კომპლექსური არანჟირებები იმავე სიზუსტითა და ინტუიციური კონტროლით, რასაც მიჩვეული ვარ პროფესიონალურ პროგრამებში, და ეს ყველაფერი – პირდაპირ ბრაუზერში.

---

## ძირითადი ფუნქციონალის მოთხოვნები:

### 1. მთავარი სამუშაო პანელი და "Sticky" პლეერი:
*   შექმენი მთავარი პლეერის ზოლი რედაქტორის თავში. ის ვიზუალურად უნდა გამოირჩეოდეს სტემის ზოლებისგან, მაგრამ ინარჩუნებდეს საერთო დიზაინს.
*   ამ ზოლზე განათავსე **გლობალური დროის ხაზი (Timeline)**, დეტალური დროის კოდით (MM:SS:ms) და მასზე მოძრავი მთავარი კურსორით (Playhead).
*   როდესაც მომხმარებელი ქვემოთ ჩასქროლავს, ეს **მთავარი პლეერის ზოლი უნდა დარჩეს ეკრანის ზედა ნაწილში მიწებებული (sticky)**, რათა დროის კონტროლი ყოველთვის ხელმისაწვდომი იყოს.

### 2. სამუშაო გარემოს მოწინავე კონტროლი:
*   **კომპაქტური UI:** სტემის ზოლები (Tracks) უნდა იყოს ვერტიკალურად კომპაქტური, რომ მეტი მოთავსდეს ეკრანზე.
*   **ზოლების ზომის შეცვლა:** დანერგე ფუნქციონალი, რომელიც მომხმარებელს საშუალებას მისცემს, თითოეული სტემის ზოლის სიმაღლე შეცვალოს მისი ქვედა საზღვარზე მაუსის ჩავლებით და დრაგით.
*   **მასშტაბირება (Zoom):** დაამატე Zoom In/Out კონტროლი, რომელიც ჰორიზონტალურად გაადიდებს/დააპატარავებს მთლიან სამუშაო გარემოს და მასზე განთავსებულ Waveform-ებს.

### 3. კლიპების რედაქტირება - "გაჭრის" ინსტრუმენტი (Split Tool):
*   დაამატე **"Split" (მაკრატლის იკონკა)** ღილაკი ინტერფეისში.
*   მისი გააქტიურებისას, მომხმარებელს უნდა შეეძლოს ნებისმიერ Waveform-ზე კლიკით მისი ზუსტად იმ ადგილას ორ დამოუკიდებელ კლიპად გაჭრა.
*   გაჭრის შემდეგ, თითოეული ახალი კლიპის დასაწყისისა და დასასრულის რედაქტირება (Trimming) უნდა იყოს შესაძლებელი დამოუკიდებლად.

### 4. ინდივიდუალური დალუპვა (Looping):
*   დაამატე **"Loop"** გადამრთველი ღილაკი თითოეულ სტემის ზოლზე.
*   როდესაც ის ჩართულია, კონკრეტული სტემის აუდიო (ან მისი დაჭრილი ნაწილი) უნდა მეორდებოდეს უსასრულო ციკლში დაკვრის დროს. ეს ფუნქცია თითოეული სტემისთვის დამოუკიდებლად უნდა მუშაობდეს.
