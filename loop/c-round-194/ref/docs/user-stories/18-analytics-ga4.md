# ანალიტიკა (GA4 & Event Tracking)

## User Story:

**As a** პროდუქტის მფლობელი,
**I want to** მქონდეს მომხმარებლის ქცევის ანალიზის საბაზისო ინსტრუმენტები ჩემს ვებსაიტზე,
**So that I can** მივიღო მონაცემებზე დაფუძნებული გადაწყვეტილებები, გავზომო მარკეტინგული კამპანიების წარმატება და მუდმივად გავაუმჯობესო მომხმარებლის გამოცდილება.

---

## კონკრეტული ამოცანები:

### 1. Google Analytics 4 (GA4) ინტეგრაცია:

- **რა არის:** ეს არის სტანდარტი ვებსაიტის ტრაფიკის გასაზომად. გვაჩვენებს, რამდენი ადამიანი შემოდის საიტზე, საიდან მოდიან (Google, Facebook), რომელ გვერდებს ათვალიერებენ და ა.შ.

- **დავალება:** დავამატოთ GA4-ის თრექინგ კოდი ჩვენს Remix აპლიკაციაში.

### 2. მნიშვნელოვანი მოვლენების (Events) თრექინგი:

- **რა არის:** ჩვენ არ გვინდა ვიცოდეთ მხოლოდ ის, თუ რომელ გვერდზე შევიდა მომხმარებელი. ჩვენ გვინდა ვიცოდეთ, **რას აკეთებს ის.**

- **დავალება:** დავამატოთ კოდი, რომელიც GA4-ში გააგზავნის შეტყობინებას შემდეგი მოქმედებებისას:

    - `play_button_clicked` (როცა ვინმე მუსიკას უსმენს)
    - `add_to_cart` (როცა პროდუქტს ამატებენ კალათაში)
    - `begin_checkout` (როცა გადახდის პროცესს იწყებენ)
    - `purchase` (წარმატებული ყიდვა)
    - `studio_opened` (როცა ვინმე ხსნის ჩვენს უნიკალურ რედაქტორს)

---

## რატომ არის ეს კრიტიკული:

წარმოიდგინე, გავუშვით პროექტი. ანალიტიკის გარეშე, ჩვენ ვართ ბრმები. ანალიტიკით, ჩვენ შევძლებთ ვუპასუხოთ ისეთ კითხვებს, როგორიცაა:

- "ბევრი მომხმარებელი უსმენს ამ თრექს, მაგრამ არავინ ამატებს კალათაში. იქნებ ფასია პრობლემა?"

- "მომხმარებლები ამატებენ პროდუქტს კალათაში, მაგრამ არ ასრულებენ შენაძენს. იქნებ გადახდის პროცესშია რამე დამაბნეველი?"

- "რამდენად ხშირად იყენებენ ადამიანები ჩვენს 'Personal Mixdown Studio'-ს? ღირს თუ არა მასში დამატებითი რესურსის ჩადება?"
