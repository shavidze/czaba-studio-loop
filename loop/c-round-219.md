## Findings for B

- **C-R219-01 (Low; a spec gap, not an A defect; B decides the severity).**
  - **What happens:** non-SPDX GPL spellings classify `clean`, so the GPL gate gives a false negative on them. C's probe (`probe/spellings.log`) gives `GPLv3`, `GPLv2`, `GPL2`, `AGPLv3`, `(MIT OR GPLv3)` and `MIT AND GPLv2` → `clean`.
  - **Why it is not A's defect:** A implemented §1.3 to the letter, and §3 explicitly accepts the per-token `/^A?GPL(-|$)/i` form. A raised this as R-219-1, and A's code-reviewer rated it Medium.
  - **Effect today:** none. No runtime entry in the lock uses such a spelling.
  - **The same probe confirms R-219-2:** any well-formed id that is not GPL counts as `clean`, including `Proprietary`, `Commercial`, `LicenseRef-Proprietary`, `SSPL-1.0`, `BUSL-1.1` and `CC-BY-NC-4.0`. So `clean` means "not GPL/AGPL", not "permissive".
  - **Suggestion for B:** a per-token `/^A?GPL/i` rule (it still never matches LGPL), and unknown for ids that are not recognised SPDX ids, or for `LicenseRef-*`.
  - R-219-3 (lowercase operators) and R-219-4 (an empty licence means none) are also open for B. C saw no defect in either.
- **INFO-C219-LAME-DECODER (info, for the "For Saba" legal item).** The LAME `license.txt` that C fetched today also says that LAME's *decoding* functions use GPL code (MPG123) and cannot be used in programs that are not GPL without permission.
  - The notice's statement "LAME is licensed under the LGPL" is still traceable to that page, so this is not a bug.
  - C measured the inlined WASM (223,033 bytes): it has no `decode`, `hip_decode`, `mpglib` or `mpg123` strings. The export names are minified (`e`…`o`), so this is suggestive, not conclusive, that the decoder is not compiled in. That is a hypothesis, not a confirmed fact. The extracted binary was deleted after the check.
- **INFO-C219-WARMUP-MP3 (harness lesson for C).** On a fresh machine, a bare warm-up `goto` does not pre-optimize the encoder deps. The first MP3 export can trigger a Vite re-optimize and a full reload. Next round, the warm-up should include one MP3 export (`c218-mp3.cjs` `warm` mode), then the measured run.
