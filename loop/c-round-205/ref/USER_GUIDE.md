## ინტერფეისის გაცნობა 🎨

### ზედა პანელი (Toolbar)
```
┌─────────────────────────────────────────────────────────┐
│ ← Downloads    ⏮ ⏸ ▶️    Middle East    Export 📥      │
└─────────────────────────────────────────────────────────┘
```

- **← Downloads**: დაბრუნება Downloads გვერდზე
- **⏮ Stop**: შეჩერება და 0:00-ზე დაბრუნება
- **▶️/⏸ Play/Pause**: დაკვრა/პაუზა
- **Product Title**: პროდუქტის სახელი
- **Export**: ექსპორტის დიალოგის გახსნა

### Timeline (დროის ხაზი)
```
┌─────────────────────────────────────────────────────────┐
│  00:05 / 02:30          100%  [-] [+]                   │
│  ├──|──|──|──|──|──|──▼──|──|──|──|──|──|──|──|──┤     │
└─────────────────────────────────────────────────────────┘
```

- **დროის ჩვენება**: მიმდინარე დრო / მთლიანი ხანგრძლივობა
- **Zoom**: [-] ზუმის შემცირება, [+] ზუმის გაზრდა (50% - 400%)
- **Playhead (▼)**: ვერტიკალური ხაზი რომელიც აჩვენებს მიმდინარე პოზიციას
- **Timeline Click**: დააწკაპუნეთ timeline-ზე რომელიმე ადგილას გადასასვლელად

### სტემის ტრეკი (Track)
```
┌──────────────────┬──────────────────────────────────────┐
│  Bass Drum       │  [════════════════▶═════]            │
│  2.5s        📥  │                                      │
│  [S] [M] [L]     │                                      │
│  Vol ▬▬▬●▬ 85    │                                      │
└──────────────────┴──────────────────────────────────────┘
```

**მარცხენა პანელი:**
- **სახელი**: სტემის დასახელება
- **ხანგრძლივობა**: სტემის სიგრძე წამებში
- **📥 Download**: ინდივიდუალური სტემის გადმოწერა
- **[S] Solo**: მხოლოდ ამ სტემის მოსმენა
- **[M] Mute**: ამ სტემის დადუმება
- **[L] Loop**: loop რეჟიმის ჩართვა/გამორთვა
- **Vol**: ხმის დონის რეგულირება (0-100)

**მარჯვენა პანელი:**
- **Waveform**: აუდიო ტალღის ვიზუალიზაცია
- **Trim Region**: ყვითელი (amber) რეგიონი დასარედაქტირებლად
- **Progress**: მწვანე (teal) პროგრესი აჩვენებს რა ნაწილი დაიკრა

## ძირითადი ფუნქციები 🎹

### 1. დაკვრა და პაუზა

**როგორ გამოვიყენო:**
1. დააჭირეთ **▶️ Play** ღილაკს ცენტრში
2. მუსიკა დაიწყებს დაკვრას
3. პაუზისთვის დააჭირეთ **⏸ Pause**
4. სრულად შესაჩერებლად (0:00-ზე დასაბრუნებლად): **⏮ Stop**

**Timeline-ზე გადახვევა:**
- დააწკაპუნეთ timeline-ზე სასურველ ადგილას
- Playhead ავტომატურად გადავა იქ
- თუ დაკვრა იყო ჩართული, გააგრძელებს ახალი პოზიციიდან

### 2. ხმის რეგულირება (Volume)

**როგორ გავზარდო/შევამციროთ ხმა:**
1. იპოვეთ "Vol" სლაიდერი ტრეკის მარცხენა პანელზე
2. გადაათრიეთ სლაიდერი:
   - **მარცხნივ**: ხმის შემცირება
   - **მარჯვნივ**: ხმის გაზრდა
3. ციფრი მარჯვნივ აჩვენებს მიმდინარე დონეს (0-100)

**რჩევა:** სხვადასხვა სტემების ხმის დონეების შეცვლით შეგიძლიათ შექმნათ საკუთარი მიქსი!

### 3. Solo და Mute

### Solo (S ღილაკი)

**რა არის Solo?**
როცა Solo-ს ჩართავთ, მხოლოდ ის სტემი ისმის, დანარჩენი ავტომატურად დუმდება.

**როგორ გამოვიყენოთ:**

**ვარიანტი 1: Exclusive Solo (მხოლოდ ერთი)**
- დააწკაპუნეთ **[S]** ღილაკზე
- ღილაკი გახდება **ყვითელი** 🟡
- მხოლოდ ეს სტემი ისმის
- დანარჩენი ავტომატურად დადუმებული იქნება

**ვარიანტი 2: Multi-Solo (რამდენიმე ერთად)**
- დააჭირეთ **Ctrl** (Windows) ან **Cmd** (Mac) + **[S]**
- შეგიძლიათ რამდენიმე სტემი ერთად გახადოთ Solo
- მაგ: Bass + Drums Solo → მხოლოდ ისინი ისმის

**Solo-ს გამორთვა:**
- კვლავ დააწკაპუნეთ **[S]** ღილაკზე
- ღილაკი გაუფერულდება
- ყველა სტემი ისევ ისმის

### Mute (M ღილაკი)

**რა არის Mute?**
Mute დუმებს კონკრეტულ სტემს.

**როგორ გამოვიყენოთ:**
- დააწკაპუნეთ **[M]** ღილაკზე
- ღილაკი გახდება **წითელი** 🔴
- ეს სტემი აღარ ისმის

**Mute-ს გამორთვა:**
- კვლავ დააწკაპუნეთ **[M]**
- ღილაკი გაუფერულდება
- სტემი ისევ ისმის

**მნიშვნელოვანი:** Mute > Solo (პრიორიტეტი)
- თუ სტემი Mute-დაა, Solo ვერ აჩენს მას
- ჯერ გამორთეთ Mute, შემდეგ ჩართეთ Solo

### 4. Trim Region (ჭრა და რედაქტირება) ✂️

**რა არის Trim Region?**
Amber (ყვითელი) ფერის რეგიონი waveform-ზე, რომელიც განსაზღვრავს რომელი ნაწილი დაიკრას და გადმოიწეროს.

**როგორ გამოვიყენოთ:**

**1. Region-ის გადაადგილება:**
- დააწკაპუნეთ region-ის შუაგულში
- გადაათრიეთ მარცხნივ ან მარჯვნივ
- მთელი region გადაადგილდება

**2. Region-ის ზომის შეცვლა:**
- **მარცხენა სახელური**: დასაწყისის დროის შეცვლა
- **მარჯვენა სახელური**: დასასრულის დროის შეცვლა
- გადაათრიეთ სახელურები რომ დააჭრათ არასასურველი ნაწილები

**მაგალითი:**
```
Original:  [────silence────][═══music═══][────silence────]

After Trim:                [═══music═══]
                          ↑ trim start  ↑ trim end
```

**რა ხდება:**
- **Playback**: მხოლოდ trim region-ში დაიკვრება
- **Export**: მხოლოდ trim region გადმოიწერება
- **Loop**: loop მხოლოდ trim region-ში მუშაობს

### 5. Loop (ციკლური განმეორება) 🔁

**რა არის Loop?**
Loop-ით შეგიძლიათ კონკრეტული მონაკვეთი უსასრულოდ გაიმეოროთ.

**როგორ დავალუპოთ მონაკვეთი:**

**ნაბიჯი 1: მონიშნეთ რეგიონი**
1. Trim Region-ის სახელურებით აირჩიეთ სასურველი მონაკვეთი
2. მაგ: 00:30 - 01:00 (30 წამიანი ციკლი)

**ნაბიჯი 2: ჩართეთ Loop**
1. დააწკაპუნეთ **[L]** ღილაკზე
2. ღილაკი გახდება **მწვანე (teal)** 🟢
3. გამოჩნდება **ვიზუალური ინდიკატორები**:
   - ✨ Trim Region გახდება **უფრო ნათელი** (brighter amber)
   - 🟡 Waveform-ის გარშემო **amber border** გამოჩნდება
   - 🔁 მარჯვენა ზედა კუთხეში **"LOOP 🔁"** badge

**ნაბიჯი 3: დაუშვით**
1. დააწკაპუნეთ **Play**
2. როცა playback მიაღწევს trim end-ს → **ავტომატურად ბრუნდება** trim start-ზე
3. ციკლი უსასრულოდ გაიმეორება

**Loop-ის გამორთვა:**
- კვლავ დააწკაპუნეთ **[L]** ღილაკზე
- ღილაკი გაუფერულდება
- ვიზუალური ინდიკატორები გაქრება

**რჩევა:**
- შეგიძლიათ რამდენიმე სტემზე ერთდროულად Loop ჩართოთ
- თითოეულს შეიძლება სხვადასხვა trim region ჰქონდეს
- მაგ: Drums loop 4 ტაქტი, Bass loop 2 ტაქტი

### 6. Zoom (მასშტაბი) 🔍

**როგორ გავზარდო/შევამციროთ Timeline?**

**Zoom Controls** (Timeline-ის მარჯვენა მხარეს):

**როდის გამოვიყენოთ:**

- **100%**: ნორმალური ხედი
- **200-400%**: პრეციზული რედაქტირებისთვის (trim region-ების საზუსტად მოსაწესრიგებლად)

**რჩევა:** უფრო დიდი zoom → უფრო ზუსტი trim region მოწესრიგება

### 7. ინდივიდუალური სტემის გადმოწერა 📥

**როგორ გადმოვწერო ერთი სტემი:**

1. იპოვეთ სასურველი სტემი
2. მარცხენა პანელზე დააწკაპუნეთ **📥** ღილაკზე (სტემის სახელის გვერდით)
3. სტემი ავტომატურად გადმოიწერება:
   - **ფორმატი**: WAV (მაღალი ხარისხი)
   - **ფაილის სახელი**: `Bass-Drum-0.5s-2.3s.wav` (სტემი + trim range)
   - **შინაარსი**: მხოლოდ trim region-ის ნაწილი

**მაგალითი:**
```
Bass Drum სტემი (duration: 3.0s)
Trim Region: 0.5s - 2.3s
Volume: 85%

Download → Bass-Drum-0.5s-2.3s.wav
  - ხანგრძლივობა: 1.8s (2.3 - 0.5)
  - ხმის დონე: 85% applied
```

**რჩევა:** გამოიყენეთ ეს თუ გჭირდებათ:
- კონკრეტული სტემის ცალკე გადმოწერა
- სხვა DAW-ში გადატანა (Ableton, FL Studio, etc.)
- სწრაფი backup

### 8. Export (სრული მიქსის გადმოწერა) 💾

**როგორ ექსპორტი გავაკეთოთ:**

**ნაბიჯი 1: გახსენით Export Dialog**
1. დააწკაპუნეთ **Export** ღილაკზე (ზედა მარჯვენა კუთხე)
2. გაიხსნება Export დიალოგი

**ნაბიჯი 2: აირჩიეთ Format**
- **WAV**: Lossless, მაღალი ხარისხი (რეკომენდებული)
- **MP3**: Compressed, მცირე ზომა

**ნაბიჯი 3: აირჩიეთ Quality**
- **LOW**: 128kbps (MP3), 16-bit (WAV)
- **MEDIUM**: 192kbps (MP3), 24-bit (WAV)
- **HIGH**: 320kbps (MP3), 32-bit (WAV) - რეკომენდებული

**ნაბიჯი 4: Normalize**
- **ON**: ავტომატურად ანორმალებს ხმის დონეს (რეკომენდებული)
- **OFF**: ინარჩუნებს თქვენს volume დონეებს

**ნაბიჯი 5: აირჩიეთ სტემები**
- **Select All / Deselect All**: ყველა ერთად ჩართვა/გამორთვა
- **Checkboxes**: მონიშნეთ რომელი სტემები უნდა ჩაერთოს

**ნაბიჯი 6: Export**
1. დააწკაპუნეთ **Export** ღილაკზე
2. დაელოდეთ პროგრესს (1-10 წამი)
3. ფაილი ავტომატურად გადმოიწერება

**Export ფაილის სახელი:**
```
Middle-East-export.wav
Middle-East-export.mp3
```

**რჩევა:**
- WAV გამოიყენეთ: პროფესიონალური რედაქტირებისთვის
- MP3 გამოიყენეთ: გაზიარებისთვის, ონლაინ ატვირთვისთვის

## რეალური გამოყენების სცენარები 🎬

### სცენარი 1: ინტრო/აუტროს ამოჭრა

**პრობლემა:** სტემებს აქვთ silence დასაწყისში და ბოლოში

**გადაწყვეტა:**
1. Play დააჭირეთ და იპოვეთ სად იწყება მუსიკა (მაგ. 00:03)
2. ყველა სტემზე Trim Region-ის **მარცხენა სახელური** გადაათრიეთ → 00:03
3. იპოვეთ სად მთავრდება მუსიკა (მაგ. 02:45)

## ხშირად დასმული კითხვები ❓

### Q: რატომ არ იტვირთება სტემები?
**A:** დარწმუნდით რომ:
1. Dev server ეშვება (`npm run dev`)
2. სტემები არსებობს `public/stems/middle-east/` ფოლდერში
3. ინტერნეტ კავშირი სტაბილურია

---

### Q: როგორ დავაბრუნო Trim Region-ის ცვლილებები?
**A:** ამჟამად Undo ფუნქცია არ არის. გეგმავენ Double-Click Reset:
- Double-click on region → რესეტდება full duration-ზე

---

### Q: შემიძლია სხვადასხვა სტემს სხვადასხვა Trim Region ჰქონდეს?
**A:** დიახ! თითოეულ სტემს აქვს საკუთარი Trim Region. მაგალითად:
- Bass: 00:00 - 02:30 (full)
- Drums: 00:05 - 02:25 (trimmed intro/outro)
- Guitar: 01:00 - 02:00 (solo section only)

---

### Q: Loop-ის დროს რატომ არ ისმის სხვა სტემები?
**A:** შეამოწმეთ Solo დაყენებები:
- თუ ერთი სტემი Solo-დაა, დანარჩენი **Implicitly Muted**-ია
- გამორთეთ Solo ან დაამატეთ Multi-Solo (Ctrl+Click)

---

### Q: Export-ში რატომ არის ხმა ძალიან დაბალი/მაღალი?
**A:** გამოიყენეთ **Normalize** ოფცია:
- Export Dialog → Normalize Audio: **ON**
- ავტომატურად დაარეგულირებს ოპტიმალურ დონეზე

---

### Q: შემიძლია MP3 320kbps-ზე მაღალი ხარისხით Export?
**A:** MP3-ს მაქსიმუმ 320kbps აქვს. უფრო მაღალი ხარისხისთვის:
- გამოიყენეთ **WAV** format → Lossless quality

---

### Q: როგორ შევინახო ჩემი რედაქტირებული პროექტი?
**A:** ამჟამად პროექტის შენახვა Firebase-ში დაგეგმილია. ახლა:
- Export გააკეთეთ როცა რედაქტირება დაასრულეთ
- ფაილი ლოკალურად შეინახება თქვენს კომპიუტერში

---

### Q: შემიძლია სხვა DAW-ში (Ableton, FL Studio) გადატანა?
**A:** დიახ!
1. Export ყველა სტემი ცალ-ცალკე (📥 Download ღილაკით)
2. ან Export სრული მიქსი WAV ფორმატში
3. Import თქვენს DAW-ში

## რჩევები და ხრიკები 💡

### რჩევა 1: სწრაფი მიქსის ბალანსი
Solo ღილაკით სწრაფად შეადარეთ ინსტრუმენტები:
1. Solo Bass → Volume დაარეგულირეთ
2. Solo Drums → Volume დაარეგულირეთ
3. Solo Bass + Drums (Ctrl+Click) → შეადარეთ balance
4. გაიმეორეთ დანარჩენ სტემებთან

### რჩევა 2: ლუპის სინქრონიზაცია
რამდენიმე სტემის loop-ის ერთდროულად მოსასწორებლად:
1. პირველ სტემზე დააყენეთ იდეალური loop region
2. დანარჩენ სტემებზე გაიმეორეთ იგივე start/end დრო
3. ყველაზე ჩართეთ Loop ([L])

### რჩევა 3: Zoom გამოყენება რედაქტირებისთვის
1. Zoom 50% → მთელი ტრეკის დასანახავად
2. იპოვეთ სასურველი მონაკვეთი
3. Zoom 200-400% → პრეციზული trim region მოწესრიგება
4. Zoom 100% → საბოლოო შედეგის დასანახავად

### რჩევა 4: თანმიმდევრული Export
თუ გჭირდებათ რამდენიმე ვერსია:
1. **Full Mix**: Export All stems
2. **Instrumental**: Mute vocals → Export
3. **Acapella**: Mute instruments → Export vocals only
4. **Drums Only**: Solo Drums → Export

### რჩევა 5: ხარისხის კონტროლი
Export-ის წინ ყოველთვის:
1. Play სრული ტრეკი დასაწყისიდან ბოლომდე
2. შეამოწმეთ ყველა Trim Region
3. შეამოწმეთ Volume levels (არც ძალიან ხმამაღალი, არც დაბალი)
4. Export → High Quality
