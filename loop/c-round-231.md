## 4. Bug

**C-R231-01 (Low; extends the pre-existing deferred C-R139-02; Playwright-emulation only so far).**
- **Steps:** fresh `/studio-lab`, empty project, Music active. Real mouse down on the first library option, move over the Music lane (the ghost shows and the hint hides), press Escape, move back to the library and release.
- **Result:** `arrangement-drop-ghost` "00:05.000" stays on Music, and the lane hint stays hidden (`hints:[]`, 0 clips). Clicking the Stems lane moves the hint to Stems. Re-activating Music shows **no** hint while the stale ghost is still there.
- **Expected:** a cancelled drag clears the ghost, and the empty active lane shows its hint again.
- **Evidence:** `c-round-231/out7/cancel-A-escape-{1440x900,1280x720}.png` and `out7/c231g.json`. Event log `out8/c231g.json`: under Playwright, Escape never reaches the page as a `keydown`, `dragend` fires at once, and **no `dragleave` reaches the lane**.
- **Cause in code:** the lane clears `libraryGhost` only on `dragleave` or `drop` (`ArrangementLane.tsx` l.313–329). `endLibraryDrag` on `dragend` does not clear it. This code is unchanged this round.
- **Real Chrome:** the HTML drag-and-drop model fires `dragleave` at the current target when a drag is cancelled, so a real-Chrome user may never hit this. That is still unconfirmed (Tech Lead check R139-T).
- **What is new this round:** the stale ghost now also suppresses the CALM-2b empty-lane hint on that lane.
- **Suggested fold-in:** the C-R139-02 fix (clear lane ghosts on `dragend`) also restores the hint.
