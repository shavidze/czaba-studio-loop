# SFX Scene Builder

## მომხმარებლის გზა

Universal SFX მფლობელი ჩანაწერების გვერდიდან ხსნის `/scenes/:productId` სამუშაო სივრცეს. მხარდაჭერილია ძველი Standard/Premium შესყიდვებიც. მხოლოდ ანგარიშისთვის ხელმისაწვდომი ჩანაწერები ემატება სცენას.

თითო ჩანაწერს აქვს საერთო დროის ხაზზე საკუთარი რიგი, გადაადგილება, ზუსტი მონაკვეთი და ხანგრძლივობა, დუბლირება, წაშლა, gain, pan, Fade In / Fade Out, Mute, Solo და Loop რბილი შეერთებით. Undo / Redo ინახავს ბოლო 50 ცვლილებას. ზღვარია 12 ხმა და 300 წამი.

## მოსმენა და ექსპორტი

ორიგინალი WAV იტვირთება დაცული original-access გზით. საწყისი ფაილები არ იცვლება. მოსმენა და 24-bit WAV ექსპორტი იყენებს ერთსა და იმავე საბოლოო PCM შედეგს. შერეული sample rate-ის შემთხვევაში გამოიყენება ყველაზე მაღალი წყაროს სიხშირე. გადატვირთვის გაფრთხილება ეფუძნება შეზღუდვამდე გაზომილ peak-ს; საბოლოო PCM ორივე გზაზე ერთნაირად იზღუდება.

Loop გადაფარავს მონაკვეთის ბოლოსა და დასაწყისს მითითებული crossfade-ით. საერთო Fade ფუნქცია ერთზე მაღალ გაძლიერებას არ ქმნის. მობილურზე პარამეტრები ორ სვეტად ლაგდება.

## ანგარიშზე შენახვა

`GET /api/sfx-scenes?productId=…`, `GET /api/sfx-scenes/:id` და `PUT /api/sfx-scenes/:id` ინახავს JSON დოკუმენტს ანგარიშის მფლობელისთვის. შენახული სცენა იხსნება სხვა მოწყობილობიდანაც. ორიგინალი აუდიო თავიდან იტვირთება, ხოლო წყაროები სცენის JSON-ში არ ინახება.

Backend ამოწმებს JWT მფლობელს, მიმდინარე შეძენის უფლებას, ჩანაწერების კუთვნილებასა და ყველა რიცხვით ზღვარს. შენახვისას სცენის productId ვერ იცვლება. ერთდროული რედაქტირებისას ბოლო შენახვა იმარჯვებს.

ჩართვამდე საჭიროა [017_SfxScene.sql](../../../../../backend/docs/database/scripts/migrations/017_SfxScene.sql) მიგრაცია და Backend/Store განახლება. ამ სამუშაოში მიგრაცია არ შესრულებულა.

## შემოწმება

DSP ტესტები ამოწმებს 30-წამიან სამხმიან სცენას, შენახული JSON-ის გახსნას, წყაროების უცვლელობას, Loop-ის შეერთებას, pan/Mute/Solo-ს, sample rate-ს, გადატვირთვასა და WAV-ის ყველა ნიმუშის ზუსტ დამთხვევას მოსასმენ შედეგთან. Backend ტესტები ამოწმებს ანგარიშის იზოლაციას, წვდომის დაკარგვას და საზღვრებს.

Shopping Mall-ის რეალური ორიგინალებით მიღებულია 30-წამიანი stereo, 96 kHz, 24-bit WAV; ყველა დეკოდირებული ნიმუში ემთხვევა მოსასმენ PCM-ს. ბრაუზერის სამუშაო სივრცე მოწმდება სატესტო account API-ით; production ანგარიშზე შენახვის შემოწმება მიგრაციის შემდეგ რჩება.
