## პროექტის კონტექსტი

ეს არის CZABA Store - მუსიკალური ე-კომერციის პლატფორმა ციფრული პროდუქტების (Music, Presets, SFX) გაყიდვისთვის.

**ტექნოლოგიური სტეკი:**
- Framework: Remix 2.12 + React 18 + TypeScript
- Styling: Tailwind CSS v4 (dark theme)
- E-Commerce: Shopify Storefront API (GraphQL)
- Database: Firebase/Firestore (shadow DB + backup)
- Storage: Cloudflare R2 (S3-compatible)
- Audio: WaveSurfer.js + FFmpeg
- Auth: Shopify Customer API + Firebase (social login)

**მნიშვნელოვანი დოკუმენტაციები:**
- `docs/technical/architecture/` - არქიტექტურული გადაწყვეტილებები
- `docs/technical/features/` - ფუნქციონალის აღწერა
- `vision.txt` - პრემიუმ ხედვის მანიფესტი
