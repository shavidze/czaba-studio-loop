## როგორ დაიყოფა (tech-lead, 2026-11-09) — შენი პასუხის შემდეგ
1. **S1:** ერთი stem → ახალი ხაზი Insert Marker-ზე, „Stems“ group-ში; ერთი Undo. დაკვრისას დამატებამ ხმა არ უნდა გაწყვიტოს.
2. **S2:** მთელი set ერთი მოქმედებით, ერთი Undo; ოთხივე stem ერთ მომენტში იწყება (ხმით გაზომილი).
3. **S3:** ნაყიდი ტრეკის adapter (`stem.order`-ის რიგით).
4. **S4:** ფიქსირებული „Stems“ ხაზის საბოლოო ბედი, perf-ის ხელახალი გაზომვა, 1280×720-ზე group header ჩანს (SR-420-2).

`createArrangement` და ცარიელი ეკრანი არ იცვლება — ახალი ხაზები მხოლოდ stem-ის დამატებისას ჩნდება. ყოველ ეტაპს ბრაუზერის მიღება აქვს, მათ შორის „stems ერთად ჟღერს“ ხმით და export-ის ფაილით (16 წმ, არა 64).
