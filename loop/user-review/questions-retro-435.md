## Q1. Firefox / Safari — SABA-B-12-ის ხელით შემოწმება (TLM-SABA-B-12-FIREFOX-SAFARI)
Cloud runner-ზე მხოლოდ Chromium არის. SABA-B-12-ის ხუთი ეტაპი (430–434) Chromium-ში გადამოწმებულია და გამოქვეყნებულია. Firefox-სა და Safari-ში ჯერ არავის უნახავს:
1. Clip details-ის Clip Gain / From / To ველებზე spin-ისრები (▲▼) არ ჩანს: მოსვენებულ მდგომარეობაში, hover-ზე და focus-ზე. ArrowUp/Down ისევ ცვლის მნიშვნელობას.
2. Export dialog-ის radio-ები: ცარიელი, მონიშნული და გათიშული ფორმა, focus-ის ჩარჩო.
3. Export dialog-ის progress bar: ფერადი ზოლი; Firefox-ში indeterminate მდგომარეობის კონტრასტი. ვარაუდით, ის 3:1-ზე ნაკლები იქნება (A-R432-REVIEW-RV432-1).
4. `?` sheet-ის ძებნა: ბრაუზერის ✕ არ ჩანს, ჩანს მხოლოდ ჩვენი „Clear search“ ღილაკი.
5. Studio-ს dialog-ების scrollbar: Firefox-ში OS-ის ჩვეულებრივი scrollbar იქნება, ისევე როგორც Studio-ს lane-ებზე. ეს მოსალოდნელია. Safari-ში უნდა ჩანდეს Studio-ს thumb.

**კითხვა:** გაუშვებ ამ 5 შემოწმებას Firefox-სა და Safari-ში შენს კომპიუტერზე, თუ root-ს დავაყენებინოთ Playwright Firefox runner-ზე (ROOT-REQ-PLAYWRIGHT-FIREFOX)? Safari-ს cloud-ში ვერცერთი გზა ვერ ფარავს.
**Default, თუ პასუხი არ მოვა:** ჩანაწერი Tech Lead-ის სიაში რჩება. ახალი ვადაა RETRO 450. მაშინ, L46-ის მიხედვით, ჩვეულებრივ task-ად გაიხსნება, თუ Firefox runner-ზე უკვე იქნება.
