არცერთი არ აჩერებს ლუპს; პასუხამდე default მოქმედებს.

1. **კალათის „Upgrade“ ღილაკის ფერი.** როცა მყიდველს პროდუქტი უკვე აქვს, კალათაში ჩანს accent (ნარინჯისფერი) შეტყობინება „You already own …“, მის შიგნით კი brass „Upgrade“ ღილაკია. 2b-3 ეტაპზე ღილაკი `Button`-ის primary (brass) variant-ზე გადადის. შევცვალოთ ის `accent` variant-ზე, რომ შეტყობინების ფერს დაემთხვეს? product-designer-ის რჩევა (`b-round-501/consult-product-designer.md`): **არა** — brass „Upgrade“-ს შემოსავლის მომტან მოქმედებად გამოყოფს და დღესაც ასე ჩანს. **Default: brass primary რჩება.** (SABA-Q-502-UPGRADE-VARIANT)

**ინფორმაციისთვის (კითხვა არ არის):** რაუნდი 502 ასწორებს კალათის სამ ხარვეზს, რომლებიც B-მ ბრაუზერში გაზომა: ტელეფონზე პროდუქტების სია არ ჩანდა და „Remove“ ვერ ხერხდებოდა; დაბალ ლეპტოპის ეკრანზე (მაგ. 1366×768) კუპონითა და gift card-ით checkout ღილაკი იჭრებოდა; კალათის სვეტებში მაუსის wheel არ მუშაობდა (Lenis). desktop-ის განლაგება და ღილაკების პოზიციები არ იცვლება. ერთი შესამჩნევი განსხვავება: კალათის სვეტებზე მაუსის wheel ახლა ბრაუზერის ჩვეულებრივი scroll-ია და არა Lenis-ის „რბილი“ scroll (სხვაგვარად სვეტები wheel-ით საერთოდ არ ტრიალებდა; doc 323 D1). თუ ეს კალათაში შესამჩნევად უხეშია, შეგვატყობინე (SABA-B-15-ის კონტექსტი). დეტალები: `current-task.md`, doc 323.
