# კითხვები საბასთვის — round 511-ის დაგეგმვა (2026-11-14)

## Q1. SABA-Q-511-PLAYSTEMS-WIRE-OR-REMOVE — პროდუქტის გვერდის „Play Stems“
- **ფაქტი:** პროდუქტის გვერდზე „Play Stems (N tracks)“ ღილაკი (`PlayStemsButton`) და მისი modal (`StemsPlayerModal`) კოდში არსებობს 2025-12-21-დან (3927eda), მაგრამ **არასოდეს ჩანს**. ღილაკი ელოდება version-ის `stems` სიას, ხოლო პროდუქტის მონაცემების mapper ამ ველს არასოდეს ავსებს. ბრაუზერში შემოწმდა: harbour-lights → Premium (stems-იანი ვერსია) → 0 ღილაკი, სამივე ზომაზე (`b-round-510/probe/head/head-states.json` და `probe/sketch/sketch-states.json`, მდგომარეობა STEMS). ეს უკვე round 474-ში შენიშნა B-მ (signal SIG-R473-STEMS-PLAYER-DEAD), მაგრამ შენთვის არ გვიკითხავს.
- **ვარიანტები:** (a) **წაშლა** — `PlayStemsButton` და `StemsPlayerModal` (მკვდარი კოდი; Studio-ში stems მაინც ისმის); (b) **ჩართვა** — backend-მა Premium version-ს stem preview URL-ები უნდა გადასცეს, შემდეგ ღილაკი გამოჩნდება (backend-ის სამუშაო + ცალკე დიზაინის რაუნდი).
- **Default (product-designer-ის რეკომენდაცია):** (a) წაშლა. სანამ არ უპასუხებ, ლუპი ამ ორ ფაილს არ ეხება.
