## 1. საბოლოო ვერდიქტი (ნაწილები 1–2)

- **საბოლოო ვერდიქტი (P1–P8 + Q1–Q6):** CZABA Studio-ს მონტაჟის და მიქსის ბირთვი Live 12-ის manual-ის ტექსტს ძალიან ახლოს მიჰყვება. ყველა სფერო ბრაუზერში შემოწმდა, ხმა output-ზე და WAV-ში გაიზომა. სულ 2 ბაგია (ABL-B-1, ABL-B-2, ორივე Low, ნაწილი 1). ნაწილ 2-ში ახალი ბაგი არ გამოჩნდა. Medium ან უფრო მძიმე ბაგი არ არის.
- **რედაქტირება Live-ს ჰგავს (ნაწილი 1):** clip bar = move, waveform = time selection, Ctrl/Shift multi-select, Ctrl+E, Ctrl+D, Cut Time, Alt-ით Snap-ის დროებითი შეცვლა, Z/X, Follow, მარკერები 6.4-ის მიხედვით.
- **Transport და ვიდეო:** ვიდეოკლიპი ხაზზე audio clip-ივით იჭრება და გადაადგილდება (28.2.1). სურათი playhead-ს მიჰყვება: გაჩერებულზე ზუსტად, დაკვრისას ≤ 11 ms. ვიდეოს ხმა ხაზის Mute-ით ქრება, სურათი კი გრძელდება. Space გაჩერების ადგილიდან აგრძელებს — ეს D-15-ით შეგნებული განსხვავებაა.
- **Loop:** Ctrl+L, ერთი brace, ჩანაცვლება და toggle 6.6-ის მიხედვით. Brace-ის და კიდეების drag Snap-ით მუშაობს. 3 wrap გაიზომა: 2.000 წმ ±1 block, ვიდეოც ბრუნდება.
- **ჯგუფები:** Ctrl+G, ჩადგმული ჯგუფი, დაკეცვა clip-ების overview-თი, Ungroup + Undo/Redo — 18.3-ის მიხედვით. Mute, Solo და Volume WAV-ში ზუსტია: −6 dB = 0.5012.
- **Fade-ები და envelope:** fade-ები წრფივია და ერთმანეთს არ ფარავს (6.8). კლიპის volume ხაზი Live-ის Clip Envelope-ს (27.2.3) ემთხვევა: Clip Gain-ის ფარდობითია. Move, trim და split ხმას არ ცვლის.
- **მიქსი:** Clip Gain და Volume ზუსტად 0.5012-ს იძლევა −6 dB-ზე. Waveform მხოლოდ Clip Gain-ს მიჰყვება. Pan-ზე მეორე არხი 0-ია, Solo ექსკლუზიურია, Ctrl+click — დამატებითი (18.1). მეტრებს აქვს clip-ის მითითება და გასასუფთავებელი peak (18.1.1).
- **Export:** onset-ები sample-ზუსტია (144000 / 348000). Range = ზუსტად 168000 frame და 0 LSB სხვაობა. MP3: correlation 1.000. Cancel და გადატვირთვის გაფრთხილება მუშაობს.
- **ჯერ Live-ს არ ჰგავს:** crossfade (დაგეგმილია, T12-ADVANCED), fade curve (ABL-R-12), envelope-ის snap (ABL-R-13), loop-ის ↑/↓ კლავიშები (ABL-R-11), Delete → ნაგულისხმევი (ABL-R-14), დროის ბრძანებები (ABL-R-7) და M დაკვრისას (ABL-R-10). Export-ს Live-ის render-ის პარამეტრები აკლია (ABL-R-16–18).
- **შეგნებული განსხვავებები (არა ბაგი):** ერთი playhead (D-15), ვიდეო dock-ში (D-22), ერთი ვიდეოხაზი, Ctrl+Shift+L = მონიშვნა ყველა ხაზზე, F2 = სახელის შეცვლა, Delete ყოველთვის ტოვებს სიცარიელეს, export-ის გამარტივება.
- **Saba-სთვის ყველაზე ღირებული რეკომენდაციები:** ABL-R-7 (დროის ბრძანებები, Medium), ABL-R-10 (M დაკვრისას, Medium; SRW-16 R3-ს ეხება), ABL-R-17 (ვიდეოს export, კითხვა), ABL-R-16 (ხაზების ცალკე export, ლიცენზიის კითხვა), ABL-R-12/13 (fade curve, envelope-ის snap).
- **შემოწმების საზღვარი:** `ableton-arrangement-expert` agent ამ runner-ზე ვერ გამოვიყენე (subagent tool არ არის). ყველა დასკვნა ეყრდნობა ბრაუზერში ნანახს და Live 12 manual-ის ტექსტს. Live აპლიკაციაში არაფერი დატესტილა.
- **ვერ შემოწმდა (CDP):** Ctrl/Cmd+digit, მარტო Alt, ContextMenu/Shift+F10, ნამდვილი touch, ნამდვილი OS file drag (ვიდეოს drop synthetic DataTransfer-ით შემოწმდა) და Ctrl+Shift+R (ბრაუზერის hard reload).
