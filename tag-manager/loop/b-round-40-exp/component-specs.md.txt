# Czaba Tag Manager - Component Specs

Tech stack: React 19 + TypeScript strict + Tailwind CSS v4 + Lucide React icons

All UI components follow the `forwardRef` pattern with `cn()` class merging.

---

## UI Primitives (`src/renderer/src/components/ui/`)

### Button

**File:** `button.tsx`

```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'ghost' | 'accent' | 'destructive';
  size?: 'sm' | 'md' | 'lg' | 'icon';
}
```

**Variants:**

| Variant | Background | Text | Hover | Border |
|---------|------------|------|-------|--------|
| `primary` | `bg-brand` | `text-brand-foreground` | `enabled:not-aria-disabled:hover:bg-brand-hover` | none |
| `secondary` | `bg-surface` | `text-foreground` | `enabled:not-aria-disabled:hover:bg-elevated` | `border border-outline` |
| `ghost` | transparent | `text-foreground` | `enabled:not-aria-disabled:hover:bg-elevated` | none |
| `accent` | `bg-accent` | `text-white` | `enabled:not-aria-disabled:hover:bg-accent/90` | none |
| `destructive` | `bg-destructive` | `text-white` | `enabled:not-aria-disabled:hover:bg-destructive/90` | none |

**Sizes:**

| Size | Padding | Font |
|------|---------|------|
| `sm` | `px-2.5 py-1` | `text-xs` |
| `md` | `px-4 py-2` | `text-sm` |
| `lg` | `px-6 py-3` | `text-base` |
| `icon` | `p-2` | inherits |

**Base classes:**
```
inline-flex items-center justify-center gap-1.5 rounded-md font-medium
transition-colors duration-150
focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand
disabled:opacity-50 disabled:cursor-not-allowed
aria-disabled:opacity-50 aria-disabled:cursor-not-allowed
```

Hover colours apply only while the button can act: neither `disabled` nor `aria-disabled="true"` (D-46).

**Default `type="button"`** is set automatically.

### SchemaEditor (`schema/SchemaEditor.tsx`)

Replaces the whole MetadataPanel while open (`Customize Fields` → `showSchemaEditor`).

**Structure:**
```
<div class="flex flex-col h-full">
  Header:   px-3 py-2 border-b border-outline flex items-center gap-2
    [Back: ArrowLeft, text-muted hover:text-foreground p-0.5 transition-colors]
    [Title: text-xs font-medium text-brand "Customize Fields"]
  Content:  flex-1 overflow-y-auto p-3
    <fieldset disabled={isApplying} class="min-w-0 space-y-4 disabled:opacity-60">
      [Active Fields] [Hidden Standard Fields] [Add Custom Field]
  Footer:   p-3 border-t border-outline
    [Done button - full width primary, size sm]
</div>
```

**Field row:**
```
flex items-center gap-1.5 rounded px-2 py-1.5
bg-background border border-outline text-xs
```

**Row icon buttons** (disabled with the fieldset while Applying):
```
Reorder arrow:  text-dim enabled:hover:text-foreground p-0.5   (+ opacity-30 on the edge arrow, natively disabled)
Remove (Trash2, custom field):  text-destructive enabled:hover:text-destructive/80 p-0.5
Hide (X, standard field):       text-dim enabled:hover:text-destructive p-0.5
```

**Hidden field chip:**
```
text-[10px] px-1.5 py-0.5 rounded bg-background border border-outline
text-dim enabled:hover:text-foreground enabled:hover:border-brand transition-colors
```

**Done:** label `Applying...` while `onSave` is pending, otherwise `Done`; `aria-disabled={isApplying || fields.length === 0}` and `aria-busy={isApplying}` instead of native `disabled` (D-45).

Back sits outside the fieldset and is never disabled, so it keeps plain `hover:`. The icon buttons and the chip inside the fieldset use `enabled:hover:`, and Add Field is a ghost `Button` (`enabled:not-aria-disabled:hover:`), so none of them has a hover shift while disabled (D-46).

## Component Authoring Pattern

### Template (all UI components)

```tsx
import * as React from 'react';
import { cn } from '~/lib/utils';

interface ComponentProps extends React.HTMLAttributes<HTMLElement> {
  variant?: 'default' | 'primary';
}

const Component = React.forwardRef<HTMLElement, ComponentProps>(
  ({ variant = 'default', className, ...props }, ref) => {
    return (
      <element
        ref={ref}
        className={cn(
          'base-classes',
          variant === 'primary' && 'variant-classes',
          className,
        )}
        {...props}
      />
    );
  },
);

Component.displayName = 'Component';

export { Component };
export type { ComponentProps };
```

### Rules

1. Always `forwardRef` with explicit ref type
2. Always set `displayName`
3. Always use `cn()` for class merging
4. Always accept and spread `className` (last in `cn()`)
5. Always use `type="button"` on buttons
6. Never use hardcoded colors -- only design tokens
7. Export both component and props type

## Zustand Stores

### State Architecture

```
useSchemaStore     - Field definitions (schema.json)
useFileStore       - Files, metadata cache, selection, sort
useMetadataStore   - Editing state, dirty tracking, toast
useTemplateStore   - Tag templates
usePlayerStore     - Audio playback state
```

### Store Pattern

```typescript
import { create } from 'zustand';

interface FooState {
  data: Data[];
  isLoading: boolean;
  setData: (data: Data[]) => void;
  setIsLoading: (loading: boolean) => void;
}

export const useFooStore = create<FooState>((set) => ({
  data: [],
  isLoading: false,
  setData: (data) => set({ data }),
  setIsLoading: (loading) => set({ isLoading: loading }),
}));
```

## Utility: `cn()`

**File:** `src/renderer/src/lib/utils.ts`

```typescript
import { type ClassValue, clsx } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs));
}
```

Used in every component for safe Tailwind class merging with conditional logic and external `className` override support.
